## 对照说明了什么

判别器小/大分别 224,049 / 808,417 参数；单 n 加鸟面头及判别器共 2,686,722 / 3,271,090；保留第二个独立 n 框模型则共 5,142,450 / 5,726,818。单 n 数字不含原厂 B/H 支路，不是整个机身资源或可部署结论。

困难负例训练比简单负例保留更多内部校准锚点，但扩容没有稳定改善真实剩余困难点。延长训练改善内部指标，仍未建立双 n 剩余样本的可用收益。

真实正例主要是稀疏眼锚点，鸟框内与枝条相交的其他点仍未知。训练侧仅有 1 张人工无鸟图，内部校准没有人工无鸟帧；按组、再按图抽样时，该图每次 32 轮只贡献 40 或 52 个点呈现，总数为 262,144。因此负例预算主要约束远处推导背景，不能充分约束框内枝叶和多样空场景。这支持“监督覆盖与抽样不匹配”的诊断，不证明容量永远无效，也不能把失败全归因于单个损失项。

另已生成 **40 张既有训练图、80 个点、24 个组**的独立复核队列，初始全部未知、未确认，不改生产标注。这不是 80 个已知错误。所选源图的父模型均已有落点：用见过这些图的模型给自己挖剩余失败，会得到过于乐观的候选分布。下一轮应按拍摄组交叉预测，起始权重也不能见过当前留出组，并明确抽样人工无鸟例、采集训练侧局部点判断。把当前全量训练父权重作为每折起点会泄漏该折。最终评估仍需新拍摄事件。

## 匹配本机耗时

每条流程记录 500 次，轮换顺序，RTX 4080 Laptop、CUDA float16 autocast、批次 1，使用 seed-20261027 的 32 轮内部选中权重。

| 流程 | P50 ms | P95 ms |
|---|---:|---:|
| single_base | 21.38 | 25.65 |
| single_small | 21.78 | 26.74 |
| single_large | 21.83 | 26.26 |
| two_n_base | 38.46 | 44.93 |
| two_n_small | 38.89 | 45.92 |
| two_n_large | 39.29 | 45.40 |

包含热 PNG 读取、预处理、解码及条件排序。单 n 缓存原厂 B/H 输出；双 n 包含两个独立 n。大判别器整体 P95 开销约单 n 2.4%、双 n 1.0%；但仅看触发补位的帧，双 n P95 从 42.17 增至 47.28 ms。整体百分位会掩盖单次触发成本。各模型常驻，既不是部署显存实测，也不是机身 NPU 或镜头耗时。计时波动下，小/大模型尾部先后不能解释成容量越大越快。
