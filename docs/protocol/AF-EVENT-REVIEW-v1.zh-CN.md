# 独立林鸟事件轻量复核 v1

[English](AF-EVENT-REVIEW-v1.md) | **简体中文**

2026-10-26 状态：这是采集和复核规范，**尚未收到或复核新的事件数据**。用户确认目前没有新投稿。

首批目标100–150帧、至少20个新拍摄事件，这是实际采集目标，不是统计功效计算。整组连拍保持在同一事件。
旧社区80张测试和已打开的200来源公开图，不能通过改名或重新切分变成新测试。

## 采集与事件分组

记录原图SHA-256、稳定事件ID、来源/公开授权、帧序号及渲染方法。同一次连续拍摄中的同一只鸟归同组，
不能只看文件名。看模型分数前，按每事件首/中/尾帧或其他固定规则选图；包含清晰对照、枝叶遮挡和虚焦，
保留短连拍完整变化。不能只收某模型失败图片，也不把从虚到清的过程去重掉。

原片保持不变。RAW的机内嵌入JPEG与独立RAW渲染单列。冻结384×256输入、较高清参考图、
镜头实际合焦是三个不同证据层次。

## 分两遍复核

1. 隐藏所有模型候选。人工记录有鸟/无鸟/未知；原图参考与冻结输入分别记录眼/头/整鸟的
   可用/不可用/未知。不可见或无法分辨的眼不猜点。多鸟图需指定目标身份，否则实例选择指标置未知。
2. 第一遍冻结后，展示匿名的锁定模型候选。人工判断最终选择点是否属于指定鸟、是否适合当前可用部位。
   可选点击可见眼中心以获得数值定位标签；计算框IoU仍需要真实框标注。人工“候选可用”判断不能冒充IoU或像素误差真值。

打开、翻页、自动保存只算草稿；人工明确提交后才确认。保留审核者、修订和前后值。模型没检出不等于无鸟。
AI候选、推导可见性与人工确认分开；使用独立复核工作区，不写现有生产标注数据库。

## 评价

评分前冻结权重、阈值、原图/输入哈希、区域策略及总调用预算。至少报告目标获取、错误眼点抢过有效回退候选、
以及已知可用性下的正确退头/退身。未知和无法评价项必须显示；同时报告按事件结果及帧总数，配对裁剪不增加独立事件数。

只有真实有序连拍才能评价候选保持、跳鸟及有效候选恢复所需帧数。这些仍是离线时序诊断；
镜头恢复时间和机身合焦率需要机身证据。

实际收到并人工复核新事件前，不能宣称对这些新场景已有训练改进。照片再次公开的授权与研究使用/标签确认分开。
