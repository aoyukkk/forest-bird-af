# Z8 辅助人工纠错

[English](z8-review.md) | **简体中文**

2026-10-25 起，这是标注工具首页的默认流程。打开 `http://127.0.0.1:8765/`，从冻结的 Z8 候选框开始逐图复核。旧 LLM 标注和修订保留在 `/annotate`，不作为这一轮的起始框。

## 操作

1. 默认显示 Z8 框。先检查整张 384×256 图，包括框外是否漏了鸟、头或可定位眼。各框的原始 slot 在右侧保留；slot 5 仍是辅助区域。
2. 全部正确时，点击 **确认并下一张**，或按 Enter。仅翻页、打开图片、自动保存都不会判为原厂正确。
3. 有误时，拖动框或四角调整；右侧可输入精确坐标。Delete 删除误检。**B** 补鸟框、**H** 补头框、**E** 点眼中心；只有眼边界确实清楚时用 **R** 画眼框。标全可辨部位，不猜隐藏眼，不画固定尺寸眼框。
4. 修改后点击确认。保留至少一个原框且有修改，记为“原厂部分有误”；原框全部修改或删除，或者从无框补上漏检，记为“原厂有误”。这是按逐框差异生成的纠错分类，不是错误严重程度评分。
5. 无候选不代表无鸟。有鸟就补画；检查全图确定无鸟才点 **确认无鸟**。无法确定用 **U** 画疑似区域，并点 **不确定并下一张**，该图不进入已确认导出。

Ctrl+Z 撤销、Ctrl+Shift+Z 重做，滚轮缩放，空格拖动平移，F 适应全图。左右方向键只切图。“恢复 Z8 原框”把当前内容恢复为基线草稿，不删除历史，也不自动确认。

**批量删除**：在 **V 选择 / 调框** 模式下，从空白处拖出选区，完整包住要选的框；眼点只需落在选区内。松手后查看高亮与“删除选中”按钮上的数量，按 **Delete** 或点击该按钮即可整批删除；一次 **Ctrl+Z** 恢复整批。**Shift+拖框** 可追加选择，也可从已有框内部开始框选；直接拖已有框仍是移动或调框。**Esc** 清空选择。框选本身不修改标注，也不确认图片，删除仍保留原厂基线和逐项纠错历史。

**清空所有框**：点击工具栏“清空所有框”，无需先选择，一次清掉当前图片的全部框和眼点，保留备注与画面内容判断，并回到 V。若打开了“叠加原厂基线”，会同时关闭该显示，冻结基线本身不变。清空自动保存为草稿，不确认无鸟、不翻页；一次 Ctrl+Z 恢复整批，Ctrl+Shift+Z 重做。空图时按钮禁用。

**连续标注**：工具栏下方的“连续标注 B → H → E”默认开启，并记住本浏览器的开关设置。进入没有任何框或眼点的图片时自动进入 B；已有标注则进入 V。新画鸟框后切 H，新画头框后切 E，点眼后回到 V；下一只鸟按 B 开始。看不清某部位可直接按 V 结束，或按 H/E 切到可辨部位，不强制补齐。关闭后，每次绘制完成都回到 V。删光误检不会触发 B，仍可直接确认无鸟；切换工具和开关均不确认图片。

**一键去重**：发现当前图与相邻编号的上一张重复时，直接点击顶部“去重”或底部“与上一张重复”。工具按全量编号自动取上一张（包括已隐藏图片），记录重复关系、排除当前图，并跳到下一张未被排除的图片。无需填写编号或确认弹窗；第一张没有上一张，因此按钮禁用。连续重复会关联到仍保留的代表图；不删除当前图已有标注，也不把它确认成正确或无鸟。

**去重管理**：顶部“去重管理”打开分组窗口；默认勾选“隐藏重复图”，队列、翻页和确认后的跳转会跳过被折叠的图片。取消勾选可显示全部；左侧“重复”筛选及按编号搜索始终可以找回重复图。已确认图片也参与去重，但保留各自的标签、状态和每次修订，“导出已确认可用记录（去重）”会排除重复图；归档用的已确认 / 所有记录完整导出仍包含它们；队列进度按当前是否隐藏重复图计算，窗口中另列全量已确认数。当前打开的图片不会因扫描突然被换走。

“重新扫描全部图片”使用 CPU 检查冻结的 384×256 输入，先备份数据库，再比较哈希、颜色、全局结构、局部变化和清晰度；有人工部位标注时同时检查其区域。高度相似图片直接匹配代表帧，优先保留已确认记录，不通过相似链无限合并；明显变化帧仍显示。所有相似组属于工程建议，不是人工确认的连拍或最终训练划分。展开组可看缩略图；“保留本图”撤回折叠，并在后续扫描中保留此选择。也可填写代表图编号，点击“标记本图重复”手动折叠当前图。

`GET /api/z8-review/export?scope=usable` 导出去除重复图后的已确认可用记录；`confirmed/all` 保留原有归档语义。

分组写入工作区 `dedupe/current.json` 及不可覆盖的运行记录；不删除照片、不转移框、不修改标注数据库。新增或更换输入会使旧结果失效，重新扫描后恢复隐藏。命令行入口：`python scripts/dedupe_annotator.py --workspace <工作区>`。`GET /api/z8-review/dedupe` 读取队列分组，`POST` 接受 `action=scan`、`action=previous` 与 `image_id`（一键同上一张），或 `action=keep/hide` 与 `image_id`（hide 另需 `representative`）。

“查看原图参考”可打开本图的只读参考图；查看后可勾选“已查看原图参考”。打开窗口本身不确认图片，标注坐标仍绑定 384×256 输入。

修改自动保存，确认后再修改会重新变为草稿。断网或刷新时可恢复本机未保存草稿；修订冲突时先下载草稿，再载入最新记录。右上角可设置复核者编号、切换英文和导出记录。

**编号含义**：`fb_0496` 是图片资产编号；`p0/p1…` 是该图片冻结 Z8 输出列表中的候选编号；`n1/n2…` 是你新画的形状编号。它们都不自动表示第几只鸟。`slot 0…5` 才是原厂类别槽。同一只鸟可有多个候选，同一 slot 也可以在多只鸟上重复。当前纠错格式尚未建立鸟实例关联；多鸟 AF 评测需要另外关联各鸟的头和眼。

## 记录和导出

`forest-bird-z8-correction-v1` 与历史精标的 `forest-bird-input-manual-v1` 独立保存。所有输入身份和 Z8 原始预测保持冻结，逐框记录保留项、修改前后值、新增项、删除项及涉及部位；每次保存增加修订，保留操作者和时间。

- **已确认记录**：人工明确确认的正确、部分有误和有误图片，均保留。
- **所有已存记录**：包括草稿和待确认。尚未操作的图片不伪造为空标注。
- **待确认记录**：无法判断的图片，单独处理。

界面按原始 slot 给框着色，人工类型与原始 slot 分开记录。辅助框不自动变成整鸟训练标签；多鸟的部位关联及具体训练格式转换需后续适配。纠错记录可用于筛选困难样本，但不直接冒充最终 YOLO 训练标签。正确样本也要保留，后续用于保持原有能力与检查退化。

这是 **Z8 辅助复核**，不是独立盲标测试真值。需要独立评测时，另行使用隐藏候选的精标流程；不要把“看过 Z8 后接受”与独立标注混称。当前坐标和可见性只描述 384×256 输入，不证明相机实际合焦。

## 人和 AI 的接口

人和 AI 读取同一份记录。AI 可以保存草稿，不能自动确认原厂正确性；当前人工复核阶段不自动运行 LLM。

| 接口 | 用途 |
|---|---|
| `GET /api/z8-review/schema` | 字段、类别和状态说明 |
| `GET /api/z8-review/dataset` | 本轮队列与状态 |
| `GET /api/z8-review/{id}` | 原始基线、当前复核和修订 |
| `PUT /api/z8-review/{id}` | 提交 `base_revision`、完整 `review`、`actor`、`action` |
| `GET /api/z8-review/{id}/history` | 本轮不可覆盖的修订 |
| `GET /api/z8-review/export?scope=confirmed` | 已确认 JSONL |
| `GET /api/z8-review/export?scope=all` | 全部已保存记录 |
| `GET /api/z8-review/export?scope=uncertain` | 待确认记录 |

`action` 为 `draft / confirm / uncertain`；后两项只允许人工。先 GET，再修改完整 `review`，保留身份字段和基线哈希；使用当前修订号写入，过期返回 409。原框 ID 为 `p0…`，新框为 `n1…`，新增时递增 `next_id`，不重复使用 ID。不能将 AI 的 `actor.kind` 改成人工绕过确认。

存储沿用工作区 `annotations.sqlite3`，新增 `z8_reviews`、`z8_review_history` 两张表。数据库备份同时包含历史精标和本轮纠错；正式工作区与测试工作区分开。
