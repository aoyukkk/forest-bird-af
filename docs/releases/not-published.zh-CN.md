# 未发布内容与原因

本页列出本地已有、但**没有**进入公开仓库的产物，以及不发布的具体理由。目的是让外部
读者能判断哪些结论可以独立复核、哪些只能复现而无法直接下载。

## 1. 厂商侧资产

| 产物 | 本地位置 | 不发布原因 |
|---|---|---|
| 原厂 `resource744.body.bin` 及其他模型包 | 本地 Z8 模型包 | 厂商数值权重，与固件资产同源 |
| 二进制固件与解包产物 | 本地固件工作区 | 厂商固件 |
| 原厂后处理查表、阈值表 | 本地模型包 | 厂商实现 |
| `z8models` 执行器全部源码 | 本地模型包 | 与权重包绑定的厂商结构描述 |

仓库内外只发布对这些资产的**分析结论和哈希**，例如
[模型与验证](../../README.zh-CN.md#模型与验证)、[解包说明](../format/UNPACK-GUIDE.md)、
[原生检测头微调](../training/z8-native-head-finetune.zh-CN.md)。

## 2. 候选微调权重

| 项 | 值 |
|---|---|
| 文件 | `resource744.finetuned.body.bin` |
| 体积 | 1,543,726 字节 |
| 变化字节 | 2,248 字节（允许范围内 1,350 个 FP16 参数） |
| SHA-256 | `7171a42d8e9148ba9dd534f5096914818715ad414fed74a60964406cba781a0a` |

不发布原因：候选文件的绝大部分字节仍是厂商权重，发布它等于发布原厂模型。替代方案是
发布哈希、字节差异范围、允许更新参数掩码和复现脚本，使他人能用自己的合法副本重跑。

## 3. 照片与公开副本

| 产物 | 说明 |
|---|---|
| 接收区原片（694 个资产） | 保持原路径、文件名、字节和 EXIF，不移动不改写 |
| 384×256 冻结输入 PNG | 可从 Releases 的公开副本按固定预处理重建 |
| 公开副本 | 通过五批 Releases 分发，用 `SHA256SUMS.txt` 核对 |

不发布原因：仓库只放清单、哈希与标签；照片版权归各摄影者，授权按批次逐条记录。

## 4. 数据库与私有映射

| 产物 | 不发布原因 |
|---|---|
| `annotations.sqlite3` 生产标注库 | 含原图绝对路径、原资产哈希、参考图哈希、复核者标识 |
| 去重记录 | 含内部来源关系与视觉候选关系 |
| 任务清单与逐次执行快照 | 含原片路径 |
| 摄影者与授权凭证 | 隐私与授权范围 |

公开的替代品是[已标注结果](../../data/annotations-2026-10-25/README.zh-CN.md)里的瘦身标签文件，
`removed_fields` 明确列出剔除的字段。

## 5. 未完成的结论

以下方向已有代码或局部证据，但**没有**形成可发布结论，因此不写进任何效果声明：

- 整机 AF 闭环、相位测距与镜头驱动。
- 机身实际合焦率、眼锁成功率、追焦表现。
- 独立盲标真值与双人裁决。
- 扩大模型规模、全网络重训或蒸馏的收益。
