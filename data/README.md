## 分组原则

**三组必须分开收，不能混。**

| 组 | 内容 | 用途 |
|---|---|---|
| A 遮挡失败 | 有鸟但没对上、被遮挡 | 主要优化目标 |
| B 正常对照 | 对得准的、清晰无遮挡 | 防止退化的护栏 |
| C 应放弃 | 遮挡过重、人眼亦难辨 | 回退逻辑判据 |

只收 A 组会导致模型过度敏感，在树叶上乱锁。C 组若混入 A 组，会教出"有鸟就必须锁点什么"的错误行为。

## 硬规则

1. **同一拍摄序列不跨数据划分。** 同一只鸟、同一地点的连拍必须落在同一 split。
2. **原图不得清晰化后送模型再当原图结果。**
3. **模型漏检不等于负样本。** 两边都漏的图保留为待人工复核，不标成无鸟。
4. **标注在模型实际输入尺度下判定。** Z8 为 384×256，a1 II 部位检测为 320×320。原图看得清但缩下去看不清的，属于分辨率问题，不是遮挡。
