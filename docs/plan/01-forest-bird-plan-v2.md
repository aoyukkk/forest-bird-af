# 林鸟遮挡定向优化方案 v2：跨机型辅助标注与原生 744 微调

2026-10-23。状态：方案，尚未下载/解包 Sony 固件、提取 Sony 模型、运行模型或训练。本轮仅核查公开项目、PR 代码及讨论，并读取已有 Z8 研究资料。服务器没有新增任务。

本方案根据用户的新目标调整优先级：先处理树叶/树枝遮挡下的鸟类漏检、部位误锁与错误目标切换。此前 YOLO26m 教师、完整三类数据集和 YOLO26n 替换的方案保留为历史版本，**暂不作为本版主线，也不继续执行其下载/训练安排**。

## 1. 本版目标

**保留 Z8 擅长的小鸟识别与原生部署结构，利用其他相机在特定遮挡场景的互补输出，以及清晰—遮挡配对样本，减少定向微调的标注成本。**

用户提到的 a1 II 对小鸟识别不如 Z8，作为需要尊重的场景线索；本轮没有原始测试样本、镜头/设置和对照协议，不能据此判定哪台相机所有场景更强。同样不能因为机型更新，就认定其检测模型适合担任全局教师。

最终任务仍是：同一只鸟有可锁眼则锁眼；眼不可用时退到头；头不可用时退到身体；均无有效部位则丢失。重点是提升遮挡场景，保留无遮挡、极小鸟和无鸟背景表现。

## 3. 从解包到“可辅助标注”的四个条件

1. **固件可解包。** 官方来源、版本、文件大小、哈希、容器/分区范围自洽；失败停止，不用随机解码可读字符串当成功。不把未知密钥的新硬件研究列为本轮必达事项。
2. **鸟类资产可定位。** 找到完整图/权重/常量、调用者与输出消费者；识别模型究竟在哪个处理器/加速器执行，更新包是否包含完整资源。主 CPU 文件系统可读不证明独立 AI 子系统的全部模型已拿到。
3. **模型可离线执行。** 恢复输入平面、数值范围、resize/ROI、算子、量化/浮点及输出 ABI，能在任意测试图上产生可解释结果。原始图、运行时和后处理分别记录；不能把不支持算子填零，或用另一个网络代跑。
4. **输出有标注价值。** 人工小集上验证眼/头/身含义、定位、可见性和误报，确认相对 Z8 的互补场景。没有机身输入/输出对照时，仍保留“机内等价未验证”；可用候选必须经人工核对后才能当标签。

模型资产可提取但无法运行时，停在资产审计，不宣称已经获得教师。只拿到 UI 对焦框/单个选中点，也不能当作完整多目标检测框和置信度；可评估它能否作人工标注提示，但不能冒充 logits 蒸馏。

Sony 官方鸟类对焦说明确实涉及眼、头、身体识别，但这不证明本项目已经恢复对应模型。[a1 II 官方对焦说明](https://support.d-imaging.sony.co.jp/support/ilc/autofocus/ilce1m2/en/13.php)

## 4. 不把“更强教师”作为前提

把 Z8 和各已通过条件的 Sony 模型当作不同的候选标注器，先测每个场景的表现，再决定如何使用：

| 同一张图上的结果 | 处理方式 |
|---|---|
| 两者都给出几何一致的部位 | 经精度校准后可进入低风险候选池，仍需抽检 |
| Z8 漏检，Sony 检出 | 高价值补充候选，优先人工确认；不因不同品牌检出就直接当真 |
| Z8 检出，Sony 漏检 | 保留 Z8 候选，尤其是小鸟；Sony 未检出不构成负标签 |
| 眼/头类别或坐标冲突 | 加入人工审核队列，不简单投票或按原始分数取最大 |
| 两者都漏检 | 不能自动标成无鸟；保留为可能困难样本人工复核 |

分数须在相同人工 val 集上分别校准，不比较 Sony 原始 score 与 Nikon 千分制分数的大小。对齐到原图坐标和同一鸟实例；不能直接比较异构模型的原始张量。某个 Sony 模型只擅长身体而不擅长眼部时，只使用其已经验证的输出类型。

建议先用 **200 张人工校准图**：100 张无遮挡/小鸟，100 张树枝树叶遮挡，并包括无鸟/相似背景的独立检查项。教师选择依据部位误报、定位与可见性，而不是只看整鸟 recall；给抽样计数及不确定性。未证实比 Z8 更有用的场景，不启用该模型的自动监督。

## 5. “生成特定数据”的两条路径

相机识别模型用于产生候选标签/软监督，本身不会生成照片。图像构造与标签生成分开，保留每一步来源。

### 路径一：真实林鸟样本，多模型辅助标注

优先收集实际失败场景，拟定初始 **1,200 张真实林鸟图**：600 train、200 val、400 test，按拍摄序列/日期/地点/个体分组后再抽样。它们是目标配额，不是已收齐数据。

覆盖：细枝穿过头或眼、密叶遮住身体、只露头、只有部分身体、绿色背景伪装、多鸟重叠、逆光、轻微失焦/运动模糊及极小鸟。不能只收模型能检出的样本。所有可见个体均要标注，保存所属实例和部位的可锁/不可锁/不确定状态。

Z8 和可运行 Sony 模型给出建议，再由人工处理分歧与高价值补充。保留原图，不能把测试图清晰化/去遮挡后送给模型，再把它当原图上的实测结果。

### 路径二：清晰鸟图→有控制的枝叶遮挡配对

拟从历史照片或 CUB 原始图中筛出 **1,000 张训练用清晰鸟图**，先确定身体、头和眼的可靠位置。Z8 在清晰图上正确输出时也可提供初稿，不一定需要 Sony。

使用真实树枝/树叶前景及掩码进行几何合成，给每张原图约4个受控变化，得到约4,000张训练派生图。改变遮挡位置、粗细、密度、透明度/景深模糊，加入与真实场景匹配的背景复杂度；不只画黑色长方形。

从数据划分开始就绑定原图和所有派生图，禁止清晰图进train、其遮挡版本进test。若使用连续视频的相邻清晰帧传标签，需要验证运动/变形和对应关系，不能原坐标复制。

**可见性规则：**

- 身体被挡而眼仍清楚：保留眼监督，训练优先眼的能力。
- 一只眼被挡、另一只眼仍可见：只监督可锁的眼。
- 眼被枝叶遮住、头仍可辨：眼不可锁/相应监督忽略，监督头回退。
- 头被挡、身体可辨：监督身体回退，不强迫预测隐藏眼。
- 近乎完全遮挡或已无法确定：保留不确定/丢失标签，不将清晰图眼坐标硬搬成“可见眼”真值。

遮挡掩码只给出几何覆盖率，不自动等于人眼可辨识程度；在384×256实际输入上复核。保留原图可见性、遮挡覆盖和输入可分辨性三个字段。第一版不使用生成式修补或凭空生成鸟眼作为真值。

可以保留清晰样本上的身体/头部整体框定义，但可见框与推断完整框必须有明确语义，且匹配原生模型。涉及不可见结构的输出不能自动算“定位正确”。

## 6. 初版数据规模与标注成本

拟定 train：1,000 清晰底图 +4,000配对遮挡图 +600真实遮挡图 +400无鸟难负例，约 **6,000图**。其中4,000图为派生样本，不是4,000个独立拍摄场景。

val：200真实图作为主要校准集，另安排清晰/无鸟样本验证正常场景；test：400真实林鸟图 +200独立清晰小鸟图 +200无鸟背景图，约800图。所有数量需在输入盘点后形成真实清单，缺项如实保留。

这会把人工工作从“全量逐图重画所有框”转成：清晰底图确认、真实难例审核、分歧修正和独立测试集精标。但不可能完全免标注；测试真值不能由待比较模型自己生成。

以前选择的 CUB 可提供清晰底图和部位点，COCO可补负例；NABirds/其他大库先不全量扩。没有真实林鸟失败样本时，可以验证合成训练链路，但不能对真实林鸟收益下结论。

## 7. 模型与对照组调整

首版优先保持 744 原结构、输入384×256、参数与 PCNNP 输出ABI。先恢复六类语义，再完成可微实现/原权重前向对照、原样权重重编码。模型文件小不再作为换YOLO的理由。

主实验可调整为三组，前提是Sony辅助输出可用：

| 新组 | 网络 | 训练条件 |
|---|---|---|
| A0 | 原生744 | 原权重、原后处理冻结 |
| A1 | 同一744结构 | 相同人工确认标签、遮挡增强、清晰—遮挡训练及原模型正常场景保持约束 |
| A2 | 同一744结构 | 与A1同图、同GT、同预算，额外加入通过验证的Sony软监督 |

A1/A2使用完全相同最终标签；若某些GT最初由Sony建议、后经人工确认，两组都使用。这样A2−A1只检验额外Sony软监督，不将新增图、更多标注和不同训练预算混成教师收益。A1−A0表示定向微调这套方案的整体效果，不能单独归因于某一个因素。

如果只获得人工确认的硬标签、没有可解释软输出，就先做A0/A1，标为辅助标注微调，不硬称跨厂商蒸馏已完成。Sony不可运行时停在能力报告；原架构清晰—遮挡方案作为明确的独立备选，不静默代替所请求的跨机型路线。

此前YOLO26n比较暂缓，等固定图定向微调结果和可部署性明确后，再决定是否作为第四组加回。锁点选择器尽量共用；若同时改动阈值/跟踪状态机，要单独列为实验因素。

正常场景保持：训练中混入无遮挡、小鸟与无鸟图，必要时对这些样本加入原模型输出保持约束；不会只训练Sony比Z8强的遮挡图而遗忘Z8的原有优势。原始来源、输入适配和分数尺度均记录。

## 8. 验收指标

核心指标是人工真值下的**真实枝叶遮挡正确锁定率、错误锁到枝叶的比例，以及眼→头→身回退是否正确**。不能只报告生成了多少框，或模型对自己伪标签的mAP。

- 遮挡场景：身体/头/眼分项召回、眼中心误差、正确部位锁定、误锁枝叶/背景、提前降级、错误跨鸟匹配。
- 正常场景：独立清晰小鸟召回与定位、无鸟误锁；要求收益不能以明显损害这些能力为代价。
- 遮挡强度：按部位可见性、枝条是否穿眼、目标尺寸、细枝/密叶分别汇总；不要只用不可靠的单一“遮挡百分比”。
- 视频可用时：目标ID切换、丢失、重新捕获和恢复锁眼时间；没有连续视频就不报告这类实测。
- 代价：相同后端/精度、batch1下的网络和完整流程p50/p95/p99，FP16差异及候选数导致的后处理变化。静态MAC基本不变不等于总延迟严格不变。

A1/A2同图配对比较，序列按clip分组统计；用val冻结阈值和模型，test不调参。总体及各场景样本数均公开，老师漏检不等于真负例。相机真实合焦率仍需镜头闭环试验，离线锁点不能替代。
