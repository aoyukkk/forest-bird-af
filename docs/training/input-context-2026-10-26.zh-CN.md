## 两条件、两种子训练

同一no-public-head数据池、初始化快照、4096次/轮、batch32、40轮上限/12耐心、AdamW .0008，
社区/公共期望各半。20261026/20261027改变抽样和增强随机序列，共享初始化；原初始化生成seed未记录，
精确重放仍需保留的同一快照。

困难版使用5385个官方CUB训练掩膜，全部核对原始图/掩膜尺寸；另有200个仅来自社区训练图的保护区外背景裁片。
这些背景继承复核覆盖假设，是**推导监督，不是新增人工无鸟真值**。头/眼单独图不提供全局背景。
有掩膜的CUB训练图以.7概率缩放到社区长边分布（16–128px）再合成，纹理细条遮挡概率.25；
过小、遮住或落在掩膜外的眼置未知。合成存在边缘/重采样伪影，不模拟真实景深和脱焦。

200步稳定性试跑包含2510次合成呈现，梯度有限；200次抽样134次合成，几何全部合法，实际查看48张。
新基线前19轮损失和B/H验证计数复现旧轨迹，但没有宣称全部权重逐位相同。

## 固件与交付边界

帧描述符环通过2889项原始ARM64合成检查：六槽、每槽416字节，写入口0x40fed500，
0x40fed60c/0x40fed6cc返回+8/+200描述符。补齐了一段曾替代执行的帧提供链路，
但实际鸟744的ISP裁剪、色彩平面、请求时序和像素生产器仍未确认。六个缓存描述符不能换算侦测频率。
通用prepare_image默认/255，与正式后端/256不同；正式训练未使用该默认入口，不能据此判断机身归一化有错。

用户确认没有新投稿，因此新事件盲审、真实连拍和镜头测试仍待数据；
已提供[独立事件轻量复核规范](../protocol/AF-EVENT-REVIEW-v1.zh-CN.md)，没有拿旧图重划成新测试。
困难增强收益未稳定，区域组合也未校准为更强标注教师，因此没有继续增加蒸馏条件。

[机器汇总](../../experiments/input-context-2026-10-26/summary.json)保留失败结果、修订及数值证据，不含厂商二进制或照片。
原片、生产标注、旧测试保留；Sony、A800和机身部署保持暂停。

独立推理用predict_bird_hybrid.py，传入本地候选、对应calibration.json及已验证原生包；
full为一次眼网络，full-tiles为五次。输出是输入平面候选和明确假设的眼→头→鸟选择，
不是已恢复的厂商身份选择或镜头控制。

掩膜来自[Caltech官方CUB分割记录](https://data.caltech.edu/records/w9d68-gec53)，Ryan Farrell提供，

## 复现已说明的配方

使用仓库外工作区及已核验公共数据，运行前冻结哈希；精确重放本轮对照需要保留的初始化快照。

```text
python scripts/training/prepare_hard_bird_context.py --dataset ../work/parts-no-public-head.json --full-head-dataset ../work/parts-full.json --cub ../public/CUB_200_2011 --segmentations ../public/segmentations --output ../work/context
python scripts/training/train_bird_parts.py --dataset ../work/context/dataset.json --pretrained ../work/initialization --output ../work/baseline-20261026 --size n --epochs 40 --patience 12 --batch-size 32 --seed 20261026 --eye-fp-budget 3 --bird-f1-floor 0.5489473684210525 --head-f1-floor 0.6496116504854369
```

添加`--hard-context`在独立输出运行困难条件，再以20261027分别运行两条件。区域/混合评价器参数见`--help`。

```text
python scripts/training/predict_bird_hybrid.py --image input.jpg --eye-weights ../work/candidate/eye.pt --calibration ../work/candidate/calibration.json --upstream ../private-native-package --output ../work/prediction.json
```
