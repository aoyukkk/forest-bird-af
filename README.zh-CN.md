# forest-bird-af

[English](README.md) | **简体中文**

面向枝叶遮挡场景的鸟类主体识别与对焦研究，目标是 **有可用眼锁眼 → 否则锁头 → 再退到鸟身**。
这里公开社区照片、人工复核标注、Z8 原生检测头训练及独立 YOLO26 衍生部位实验，尚未验证整机自动对焦。

**694 个图片资产 · 547 条人工确认记录 · 535 条去重后可用记录**

更新于 **2026-10-27**。

## 怎样使用标注

- 以 [confirmed.jsonl](data/annotations-2026-10-25/confirmed/confirmed.jsonl) 为无损入口，
  坐标绑定冻结的 **384×256 输入**。
- 眼睛只有实际标过边界才有眼框。COCO/YOLO 视图包含 **1,041 个原有框**，
  另外保留 **160 个纯眼点**，不制造固定尺寸眼框。[格式说明](data/annotations-2026-10-25/confirmed/README.zh-CN.md)。
- COCO/YOLO 是**部分框视图**，不能直接当作完整 BHE 检测训练真值；
  缺少眼框不代表该处是背景。
- 本轮是在显示 Z8 候选后人工复核，不是独立盲标；多鸟部位的实例关联尚未建立。

## 下载后先检查

公开数据检查仅需 Python 3.11+ 标准库，不需要 GPU、照片或厂商包：

```bash
git clone https://github.com/aoyukkk/forest-bird-af.git
cd forest-bird-af
python scripts/tools/verify_annotations.py
python scripts/tools/verify_links.py
python scripts/tools/verify_repo.py
```

标注界面依赖见 [requirements-annotator.txt](requirements-annotator.txt)。
训练另需 NumPy 和适配 CUDA 的 PyTorch；原生路线还需已验证厂商包，独立 YOLO 路线使用公共数据。详见
[训练指南](docs/training/README.zh-CN.md)及[测试指南](tests/README.zh-CN.md)。
仓库不包含固件、原厂或修改后的厂商权重、特征缓存和生产标注数据库。

## 公开数据扩充与空景 — 2026-10-27

额外准入17,252张公开研究图，隔离158张并保留原文件；社区694条记录不变。
四组判别器各完成32轮。空景监督改善内部校准，但完整推理发现主检测器已有误选，
固定拒绝门控又会丢失鸟面，默认不改。A12入口未通过教师准入，伪标签为0。

## 容量与真实困难负例 — 2026-10-27

保留冻结 n 父模型，比较两种 RGB/上下文判别器，完成六组各8轮、六组各32轮。
扩容仍未在较强主策略的剩余困难图建立可用收益；已准备训练侧40张、80点独立复核队列，
没有新增确认标签。默认推理和原人工标注保留。

## 冻结鸟面分支 — 2026-10-27

四组匹配训练完成32轮，新头6945参数，共享原特征。CUB开发视图中的合成遮挡误点下降，
但真实剩余困难图仍误点枝叶，也选择了唯一人工确认无鸟图。
500次计时中，单n/双n流程P95开销分别增加3.8%/6.3%。原输出和标注保留，**本轮不推荐替换**。
[结果与局限](experiments/surface-2026-10-27/README.zh-CN.md)。

## 落点可用性复核 — 2026-10-26

51个原未评落点已完成人工确认：**可用粗引导44、不可用7**。原AI草稿与校验后的人工结果分开保存。
低门槛空候选补位仍引入过多误点；.7门槛在重复使用验证集上每种主策略仅多1个可用点。

六组匹配继续训练共48轮、27.49分钟，精细引导选型仍保留父模型。
双n部位组合把几何支持从62/80提高到68/80，保留15/25张精确眼命中。
旧/新粗捕获参考分别71/80、70/80，但精细眼偏差和未知眼选择不同。

## 输入/上下文后续轮 — 2026-10-26

困难增强在一个种子改善、另一个种子下降。

## 最新对照 — 2026-10-26

选出的 YOLO26n 衍生模型在锁定的公开原尺寸图上改善了眼点定位，但缩小至社区目标尺寸后，
鸟框召回低于原厂。**目前不推荐替换机身模型。**

| 公开测试视图 | 模型 | 鸟命中 / 200 | 眼命中 | 眼未匹配候选 |
|---|---|---:|---:|---:|
| 原尺寸 | 原厂 | 65 | 150/201 | 23 |
| 原尺寸 | n 候选 | 193 | 160/201 | 19 |
| 小目标配对视图 | 原厂 | 117 | 40/179 | 16 |
| 小目标配对视图 | n 候选 | 64 | 48/179 | 13 |

框IoU≥.5，眼≤4输入像素；阈值均在社区验证集锁定。两个视图来自同一批200张CUB，
不是新增林鸟实拍。原厂在原尺寸图IoU≥.3时鸟命中为183/200，严格未匹配框不能解释成背景误锁。
社区验证整体F1仍以原生候选较高，稀疏蒸馏保留n父权重。

[实现说明](docs/training/yolo26-parts.zh-CN.md)。

## 首轮历史测试

候选经过验证集选型后，在 80 张留出图片上测试一次。
严格离线标准：鸟/头 IoU≥0.5，眼中心误差≤4 个输入像素。

| 测试指标 | 原模型 | 候选 |
|---|---:|---:|
| 宏平均 F1 | 43.89% | 46.92% |
| 眼命中 / 标注 | 4/22 | 6/22 |
| 眼部未匹配位置误检 | 1 | 3 |
| 眼精确率 | 80.00% | 66.67% |

**检出的眼更多，误检也更多，目前不推荐替换原模型。**
后续四组继续微调未得到合格提升，均保留父权重。
测试集仅有五个保守关联组，其中 58 张同组；眼精确率只统计标有该部位的图片。
这些数字不代表机身合焦率或跟踪性能。旧测试划分保留供复现，
不能再次当作后续调参的新测试集。
