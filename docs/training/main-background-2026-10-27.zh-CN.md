# 主检测器背景微调

[English](main-background-2026-10-27.md) | **简体中文**

上一轮独立判别器过滤原有预测时损失了大量真鸟引导，本轮直接更新 B/H
检测器。训练对象是独立的 YOLO26 派生 n 模型，不是 Z8 原厂网络。
[结果与选型](../../experiments/main-background-2026-10-27/README.zh-CN.md)。

## 模型与监督

现有组合包含两个独立模型：B/H 专家与眼点专家，各 2,455,728 参数。本轮更新
B/H 模型的骨干、颈部和检测头，冻结其未使用的姿态头与 BN 运行统计。独立眼模型
完全不动，因此保留眼点结果是路由设计的保证，不是新训练提升眼识别的证据。

合并清单冻结 33,212 张输入。训练池为社区 375、CUB 5,385、NABirds 21,428、
COCO 1,899、CCT 678 张，其余属于公开／社区开发划分，不参与训练抽样。历史
测试图不进入清单。数据准入、许可和保守去重沿用[上一轮](data-expansion-2026-10-27.zh-CN.md)。

新增全图 B/H 负监督只来自上游明确独占 `empty` 类的 CCT 图。部分有行人，
监督含义是无鸟。公开数据缺少头框时保持未知；本轮不训练眼分支。既有部分标签
掩码和社区框外背景覆盖假设保留。COCO 含少量死鸟实例，按通用鸟类样本保留，
不能把全部数据称为活体林鸟。没有 A12 伪标签或生成图。

实际查看了 24 张 384×256 训练输入的 B/H 叠框：社区 12、COCO 3、NABirds 3、
CCT 6 张。这是工程检查，不新增人工确认，也不证明全部来源标签正确。
训练前冻结全部输入 SHA-256，以及独立眼模型真实单图推理的预测。

## 匹配对照

两条件的图片批次、初始化和优化设置相同。每批 12 张回放、4 张 CCT。
回放以 .7 概率按社区关联组抽样，否则等概率选 CUB／NABirds／COCO 来源。
CCT 先抽相机再抽图片。对照组屏蔽 CCT 的 B/H 损失，空景组启用 .1 权重的
分类损失。BN 统计冻结，避免对照组仅看到 CCT 就改变运行统计。

种子 20261027、20261028，每组 8 轮，每轮 96 批，batch=16。每组共 12,288
次图片呈现，不是遍历全部清单 8 次。AdamW 学习率 .00002、衰减 .0001，
FP16 autocast、FP32 损失计算、梯度裁剪 10；无几何或模糊增强。
固定输入为 RGB CHW 384×256，除以 256。

正例回放另加 .25 权重的父模型输出保持项：只在对应人工框内、父模型得分
至少 .2 的位置保持 B/H logits，并加 .02 倍原始框回归保持。父模型预测不变成
新标注。32 批试跑与正式训练分开，试跑权重不用作初始化。

## 选型与验证

评估父模型与第 2／4／6／8 轮。B/H 实际单图推理与固定眼预测组合，评估
80 张已反复使用的社区开发图、172 张 CCT 校准图，以及训练前按元数据哈希
固定的 128 张 COCO 开发图。阈值固定 E=.8、H=.4、B=.4，按 E→H→B 选择。

先要求社区几何支持至少 68/80、框外落点最多 1/80、明确无鸟图不能选点，
各项眼点计数必须与父模型完全一致。合格候选优先减少 CCT 选点，再比较社区
几何支持。第 0 轮父模型也参与选型，不能为了选出新权重而强制替换。
COCO 框 IoU≥.5、得分≥.4 的鸟框召回仅作诊断，不参与选型。

几何支持只是落点靠近已标眼或位于部位框内，不证明可见鸟面、身份、景深或
实际合焦。CCT 校准与旧社区验证均已反复使用，不能称为新盲测；目前没有
新的实拍事件留出集。缺少眼标注仍然表示未知，不计为眼检测失败。

选型后重载两个独立网络，重新计算预测，核对眼缓存与候选预测完全一致。
可选计时在 8 张固定图上交替运行父模型／候选，含传输、两个前向、解码和
最终选点，不含磁盘读图。原模型、输入、生产标注与旧测试证据通过哈希和
数据库逻辑快照读回保护。

## 命令

使用固定的可选 YOLO 环境和兼容 CUDA PyTorch，输出放在 Git 外：

```text
python scripts/training/prepare_main_background.py --help
python scripts/training/train_main_background.py --help
python scripts/training/evaluate_main_background.py --help
```

准备脚本接收 `--base`、`--admitted`、`--regions`、`--box-parent`、
`--eye-parent`、`--output`。训练接收生成的 `--dataset`、`--eyes`、原始
B/H 权重 `--initial`、`--eye-parent`、`--condition`（`control` 或 `empty`）、
`--seed` 与新输出目录。两种子均从同一父权重开始，过程中不改源代码与数据。
评估接收选中的 `--box`、对应 `--expected` 验证 JSON 和相同冻结输入。
计时另加 `--reference-box` 与 `--benchmark-repeats 120`。

权重、输入图片、私有清单和逐图预测留在 Git 外。公开代码哈希与汇总曲线用于
定位实验，不分发厂商资产或受来源许可约束的照片。
