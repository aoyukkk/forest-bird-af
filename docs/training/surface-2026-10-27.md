# Frozen-base bird-surface experiments

**English** | [简体中文](surface-2026-10-27.zh-CN.md)

**Completed:** four runs, 32 epochs; no replacement recommended. See the
[measured results](../../experiments/surface-2026-10-27/README.md).

This round tests a separate coarse capture output while retaining the existing
B/H/eye model exactly. It addresses visible bird surfaces and explicit synthetic
occluders; it does not train another precise eye label from an uncertain point.

## Model and data

The frozen n parent has 2,455,728 parameters. A 6,945-parameter head combines
stride-4 layer 2 and stride-8 neck layer 16, with 32-channel projections and
depthwise convolutions. It predicts a stride-4 surface score map. Maximum-cell
centres decode to input pixels `(4*c+2, 4*r+2)`. This is a custom YOLO26-derived
module; deployment on camera hardware is unverified.

The base parameters, running statistics and fixed batch-one float32 raw outputs
must remain unchanged. Gradients enter only the new head. In the first routing
experiment, a surface cue fills an E/H/B abstention and cannot replace an
existing target. The head shares parent features instead of adding a third
full network to the existing two-n reference.

The frozen dataset contains 5,385 CUB training images, 600 CUB development
images, 375 community training images and 80 community development images.
The new sampler uses CUB at 70% and eligible community supervision at 30%;
373 community images in 55 groups are eligible, sampled by group then image.
Missing community eyes remain unknown. Existing eyes supply sparse point
positives, without fabricated boxes or dense bird labels. Head-only records
without usable spatial supervision are excluded from this head's sampler.

The 200 background crops retain the previous reviewed-coverage assumption;
they are not 200 new human-confirmed negative scenes. CUB focal-bird masks do
not establish exhaustive absence elsewhere in an original image. Original
CUB supervision is restricted to the annotated bird region. Synthetic composites
use derived background negatives and retain their weaker provenance.

Official masks have multiple grey levels, including examples with maximum
204. Convert them using the existing `>127` foreground convention before alpha
resampling. Dividing by 255 and requiring `.98` would incorrectly label some
whole birds as background. A failed 48-view engineering audit exposed this
before GPU training; its evidence was retained, normalization was corrected,
and a regression test plus a second actual 48-view inspection followed.
Synthetic boundary/blur uncertainty is ignored; tiny birds may have no reliable
positive interior. Engineering inspections are not human label confirmation.

## Matched comparison

| Condition | Shared positive/background supervision | Explicit synthetic occluder on bird |
|---|---|---|
| R1 | Visible bird interior, sparse confirmed eyes and qualified negatives | Ignore |
| R2 | Same images, targets and sampling order | Additional negative loss |

Both conditions use seeds 20261027 and 20261028, the same head initialization,
8 epochs, 4,096 presentations per epoch, batch 16 and AdamW with initial
learning rate .001. The 200-step pilot is separate and never reused as a formal
initialization. All epoch heads and prediction records are retained.

The fixed CUB validation cache has original, small and occluded views for each
of 600 source images: 1,800 correlated views, not 1,800 independent scenes.
It uses frozen float16 features and the same training-derived background pool.
Selection maximizes mask foreground hits minus five times known background or
occluder hits. Unknowns and abstentions remain separate; costs 2 and 10 are also
reported. Thresholds and checkpoints are selected before reading new community
predictions. This is development selection, not a real-foliage accuracy claim.

The 51 previous human point judgements are evaluation records and never enter
training. A changed point cannot inherit its old judgement. Community geometric
counts retain their proxy meaning; new surface usability needs point review.
The historical 80-image test and previously opened public test are quarantined.

## Reproduction

All commands require the existing optional YOLO runtime and compatible PyTorch.
Use new output paths outside Git; photos, masks, caches, checkpoints and original
review exports stay private. CUB licensing and Ultralytics terms still apply.

```text
python scripts/training/prepare_bird_surface.py --dataset ../context-data/dataset.locked.json --cub ../CUB_200_2011 --segmentations ../segmentations --output ../surface-data
python scripts/training/train_bird_surface.py --mode pilot --dataset ../surface-data/dataset.json --parent ../parent.pt --output ../surface-pilot
python scripts/training/train_bird_surface.py --mode cache --dataset ../surface-data/dataset.json --parent ../parent.pt --output ../surface-cache
python scripts/training/train_bird_surface.py --mode train --dataset ../surface-data/dataset.json --parent ../parent.pt --cache ../surface-cache --condition R1 --seed 20261027 --output ../surface-R1-seed1
```

Repeat the final command for R2 and the second seed, retaining the same frozen
data, cache and head initialization. Training requires CUDA and does not switch
backends silently. `train_bird_surface.py` validates cache and parent hashes,
freezes BN, checks gradient boundaries and raw-output parity, and reads back
each saved head.

For an explicitly selected experimental candidate:

```text
python scripts/training/predict_bird_surface.py --parent ../parent.pt --head ../best-head.pt --calibration ../surface-calibration.json --image bird.png --primary-result ../primary-result.json --output ../surface-result.json
```

Calibration contains `capture_threshold`, `parent_sha256` and `head_sha256`.
Primary-result input hashes must match. Without a primary result, the command
produces a surface-only diagnostic. CPU inference must be selected explicitly
with `--device cpu`; it may differ from float16 CUDA near thresholds.

The experiment's measured results are recorded separately from this protocol.
Sony, remote/A800 work and camera deployment remain paused.
