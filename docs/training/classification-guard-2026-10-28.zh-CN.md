# B/H 分类头保真微调

[English](classification-guard-2026-10-28.md) | **简体中文**

本轮承接[上一轮骨干微调退化](main-background-2026-10-27.zh-CN.md)，仅训练
B/H 分类塔的 **49,158 个参数、42 个张量**。骨干、颈部、框回归、未使用姿态头、
BN 运行统计和独立眼模型均固定，保留原来的双 n 架构。这不是 Z8 原厂或 A12 训练。

## 训练回放与场景检查

沿用冻结的 33,212 张输入及 380 张开发评估输入。困难条件只从 375 张社区训练图
计算：整鸟框最大边≤32 像素、鸟框内亮度中位数≤.18，或只有头部的部分标注。
亮度按 RGB 除以 255，再以 (.2126, .7152, .0722) 加权后取中位数；它描述框内
亮度，不是假定精确鸟面掩膜。缺少鸟身／头／眼标注仍保持未知。

实际查看 12 张输入尺度叠图时，发现训练 `fb_0499`（组 `fb_0496`）与验证
`fb_0382`／`fb_0384`（组 `fb_0377`）疑似同一树洞场景。这是视觉疑点，尚非
拍摄事件身份确认。正式训练前，将 **`fb_0496` 组的全部 21 张训练图从本轮抽样
隔离**，旧划分和生产标注不变。最初试跑、其执行代码和隔离前回放清单均保留。

修订后可回放社区训练图为 354 张，其中困难池 60 张、21 个组，困难类别有重叠。
父模型已在旧划分训练，隔离不能让旧验证集变成独立测试。报告明确保留该疑点，
不宣称已清除父模型历史暴露。12 张图的检查是 AI 工程诊断，不新增人工标注。

新收到的一张本地照片逐字节复制到独立接收批次，等待标注和拍摄关系检查。本轮
不用于训练或开发评估，不公开，也未占用公开注册 ID。既有原输入和公开 694 条
快照不变。

## 匹配训练

每批 8 张普通回放、4 张困难社区图、4 张 CCT。普通回放以 .7 概率抽社区组，
否则等概率抽 CUB／NABirds／COCO 来源；困难社区与 CCT 都先抽组再抽图片。
同一种子的两条件图片顺序相同，`control` 屏蔽 CCT 的 B/H 分类损失，`empty`
以 .1 权重启用。监督来源沿用[上一轮准入](data-expansion-2026-10-27.zh-CN.md)。

种子 20261028、20261029，各 8 轮，每轮 96 批、batch=16，每组 12,288 次图片
呈现。AdamW 学习率 .000005、衰减 .0001，CUDA FP16 autocast、FP32 损失计算、
梯度裁剪 10。模型保持 eval 模式，但分类参数正常求梯度，冻结行为和 BN 与父模型
一致。不做几何或模糊增强，输入为固定 384×256 RGB CHW 除以 256。

沿用部分标签检测损失；冻结的框回归项仍计入损失数值，参数更新仅来自分类部分。
新正例保持项解码父模型框中心，在对应 B/H 人工框内，每个部位取最多三个父得分
≥.1 的锚点，仅对其 logit 下降施加平方铰链惩罚，先按目标、再按图片平均。
困难图乘二，整个保持项权重二。父预测不变成新标注，CCT 不启用正例保持。
修订后的 32 批试跑不作为正式初始化。

## 选型与读回

父模型和第 2／4／6／8 轮，在原来的社区 80、CCT 172、元数据固定 COCO 128 张
开发图上评估。阈值 E=.8、H=.4、B=.4，E→H→B 优先。沿用总量要求：几何支持
至少 68、框外最多 1、明确无鸟图不选点；另要求**不能丢掉任何父模型已支持帧**，
不能靠新增帧抵消旧帧损失；眼点各计数保持一致。逐帧保持比上一轮更强，因此
跨轮比较不是单因素消融；本轮两条件的规则和选型机会一致。

合格候选优先减少 CCT 选点，再比较社区支持，第 0 轮也可保留。COCO 框
IoU≥.5／得分≥.4 的召回仅作诊断。几何支持不证明可见鸟面、身份、景深或合焦，
未标眼不当错误。旧开发图不是新盲测，不重开历史测试。

每批核对原始框回归与父模型完全相同，每轮权重保存后读回，分类白名单外所有
状态必须与父模型一致。重新生成抽样序列核对日志哈希，并检查未抽到隔离图或
开发图。最终用 `evaluate_main_background.py` 重载两个真实网络，重新计算眼
预测，核对组合输出一致。原输入和生产状态读回证据保留在 Git 外。

## 命令

使用固定的可选 YOLO 运行时及既有 CUDA PyTorch，输出放在 Git 外：

```text
python scripts/training/prepare_classification_guard.py --dataset FROZEN_DATASET --quarantine-group fb_0496 --output FRESH_REPLAY_DIR
python scripts/training/train_classification_guard.py --help
python scripts/training/evaluate_main_background.py --help
```

训练需 `--dataset`、冻结 `--eyes`、修订 `--hard`、原始 B/H `--initial`、固定
`--eye-parent`、`--condition control|empty`、`--seed` 和新 `--output`。两个种子、
两个条件均从相同父权重开始，中途不改源代码与数据。评估接收选中的框权重及其
对应验证 JSON。[公开结果](../../experiments/classification-guard-2026-10-28/README.zh-CN.md)
只含汇总和哈希，不含权重、照片、私人路径或数据库。
