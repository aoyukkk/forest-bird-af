# Z8 / E7 对比与 CUDA 验证

[English](05-e7-comparison-and-cuda.md) | **简体中文**

运行日期：2026-10-24。本批 296 张社区照片已在本地 GPU 完成推理，后处理保留 Z8 原厂路径。207 张有候选、89 张无候选，共 660 个框，下一步进行人工复核。

## 模型身份

上游为 [WonderLantern/e7-bird-network](https://github.com/WonderLantern/e7-bird-network)，固定提交 `8ced43b19edb845baef39a80c45d40be0b49efba`，59 个文件的包完整性检查通过。

本地 Z8 C3.11 resource744 全文件长 1,543,904 字节，模型主体从偏移 176 开始，长 1,543,726 字节，与上游主体逐字节相同，SHA-256 为：

`e8d371e77efc3035d0c633c8c90aa4851f1675e5abcf7999edb23adc6439722b`

## 执行配置

| 项目 | 本轮使用 |
|---|---|
| 输入 | EXIF 校正 RGB、主图帧、Pillow 双线性拉伸 384 x 256、CHW u8 除以 256 |
| 网络 | 原主体、权重与命令顺序，采用 E7 RTZ/FTZ 算术配置 |
| GPU 适配 | 显式指定张量设备与 CUDA double-to-half 转换，算术策略固定 |
| 后处理 | 现有 BA2 实现执行本地 Z8 原厂 IPU 指令 |
| 类别 | 保留原始 slot 0-5，语义名称待确认 |

早期本地配置使用 u/255、FP16 存储和 FP32 矩阵累加，其结果与本轮分开保存。

## 验证结果

| 检查 | 结果 |
|---|---|
| 公开 stripe/random 实机样例 | 23,232 个逻辑 head half、245,760 个已定义工作区 half 逐位一致 |
| 真实图 CPU/GPU 对照 | 全部 11,616 个逻辑 head half 一致 |
| GPU 重复推理 | 逐位一致 |
| CUDA batch=16、64 | 每个样本的 head 与已定义工作区均匹配参考 |
| 两种解码器对本批 296 张输出解码 | 全部候选记录一致 |

上游实机参考来自 Nikon ZR C1.10，验证范围是所提供的网络样例。本轮测量网络输出与候选，没有做相机镜头闭环合焦测试。

上游解码表与本地 IPU 对应范围并非全部相同。虽然本批 296 张候选记录一致，实际预标注仍保留原 Z8 后处理。

## 环境与耗时

- 现有 conda `machine`，Python 3.12、PyTorch `2.7.0.dev20250117+cu126`、NumPy 1.26.4。
- NVIDIA RTX 4080 Laptop，12 GB 显存。
- NEF 审核图使用项目独立依赖目录中的 rawpy 0.25.1。

batch=64 样例验证耗时 39.87 秒，张量分配峰值约 4.65 GB。照片五个批次为 64、64、64、64、40 张，网络阶段累计 **185.95 秒**，批量摊销约 0.628 秒/张；不包含图片读写、后处理、叠图和人工复核。
