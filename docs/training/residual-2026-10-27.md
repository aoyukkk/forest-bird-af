# RGB/context ranking of residual capture candidates

**English** | [简体中文](residual-2026-10-27.zh-CN.md)

The capacity and real-hard-negative experiments are complete. They do not
justify replacing the retained primary policy. [Results](../../experiments/residual-2026-10-27/README.md).

## What was trained

The existing YOLO26-derived n parent has 2,455,728 parameters. Its parameters
and running statistics remain frozen, along with the 6,945-parameter surface
proposer from the preceding round. The new trainable module sees local RGB
pixels rather than only the frozen feature map. This is a separate verifier,
not a new end-to-end training of the whole n backbone.

Each proposed point supplies a 24-pixel and a 96-pixel square, each bilinearly
sampled to 64×64. The six RGB channels pass through five stride-2 convolution
stages and global average pooling. The classifier also sees 128 sampled frozen
P2/P3 features, the proposal score and four source-kind indicators. The small
and large verifiers have 224,049 and 808,417 parameters. One n parent plus its
surface proposer and verifier totals 2,686,722 or 3,271,090 parameters.
The two-n primary additionally retains its independent 2,455,728-parameter
box model: total 5,142,450 or 5,726,818. The single-n totals exclude native B/H
inference; these are not claims that the entire camera system has doubled.

The pool contains at most 24 points: up to 8 predicted eyes, 4 head centres,
4 bird centres and 16 surface peaks, deduplicated within 4 input pixels and
truncated in that order. No ground-truth anchor is injected at inference.
An existing E/H/B selection is retained exactly; ranking runs only after a
primary abstention. Its output is a coarse `capture_hint`, never a precise eye.

## Partial labels and calibration

The parent training split remains 375 community images. A metadata-only group
rule reserves 41 images in 5 groups for verifier calibration, leaving 334 for
verifier fitting. The parent previously saw these 41 images, so this is internal
calibration, not independent evaluation. The old 80 community validation images
remain reused development diagnostics; the historical tests stay quarantined.

Real positives are exact existing human eye anchors. Other points inside a
bird/head box are unknown. A confirmed absent frame supplies negatives; points
at least 32 pixels outside every protected box/eye/uncertain region supply
half-weight derived negatives only when a reviewed bird box exists. Head-only
frames do not establish global absence. This rule assumes review coverage;
it does not convert missing detections into negative labels.

CUB supplies 5,385 fit images and 600 calibration images. The latter produce
1,800 correlated original/small/occluded views using the existing training
background pool. Reliable mask interiors are positives, explicit synthetic
occluders are negatives, qualified backgrounds have half weight, and boundary
uncertainty is ignored. CUB masks are normalized with the established `>127`
foreground rule before alpha resampling. These data retain CUB's research
licensing and the previous background-coverage assumptions.

The cache contains 157,697 fit points, 1,250 real-calibration points and 57,089
public-calibration points. Only known labels enter fitting. Exact eye/mask
anchors and random easy negatives are added for supervision and calibration;
their injection flags and labels are absent from model inputs. Injected
anchors are excluded from public top-one proposal metrics. Real calibration
anchor recall is consequently not an end-to-end detection recall.

## Matched experiments

Three conditions, each with sampling seeds 20261027 and 20261028:

| Condition | Verifier | Real negative sampler |
|---|---|---|
| small-hard | Small | 75% mined candidates when available |
| large-easy | Large | Random qualified negatives |
| large-hard | Large | Same hard-negative rule as small-hard |

CUB negative and synthetic-occluder sampling is identical across conditions.
Frame order matches within each seed; small-hard and large-hard also match
point order. Large easy/hard models share initialization. Sampling uses 50%
CUB and 50% eligible real groups, then frames. Each epoch is 4,096 cached
frame-pair presentations, batch 64 frames, AdamW lr .0003, weight decay .0001,
CUDA float16 autocast, and clip norm 10. Loss is weighted binary cross entropy
plus .5 times a pairwise softplus ranking loss. Cached context is frozen;
RGB receives a .9–1.1 brightness gain.

Six initial 8-epoch runs all selected their terminal epoch. A separately
recorded amendment then reran the same six conditions from their matched
initializations for 32 epochs. This decision followed the first development
diagnosis. It was not pre-registered before that diagnosis. Threshold and
checkpoint selection rules did not change. All 12 runs and 240 configured
cache epochs are retained; this is not 240 full-backbone epochs.

Selection first requires at most one known-negative real-calibration frame,
then maximizes accepted real anchors, then CUB top-one foreground hits minus
five times known wrong hits; remaining ties prefer fewer false frames and a
higher threshold. An explicit abstain-all threshold is included. The old 80
community predictions and human/AI point reviews never enter this selection
or training. The surface proposer itself was selected on the same CUB
development sources in the preceding round; public calibration is not new.

## Reproduction

Use the pinned optional [YOLO dependencies](../../requirements-yolo26.txt) and
compatible CUDA PyTorch. Use fresh output paths outside Git:

```text
python scripts/training/prepare_bird_residual.py --dataset ../surface-data/dataset.json --parent ../parent.pt --surface-head ../surface-head.pt --output ../residual-cache
python scripts/training/train_bird_residual.py --cache ../residual-cache --output ../residual-pilot --condition large-hard --pilot-steps 200
python scripts/training/train_bird_residual.py --cache ../residual-cache --output ../residual-large-hard-seed1 --condition large-hard --seed 20261027 --epochs 32
python scripts/training/predict_bird_residual.py --parent ../parent.pt --surface-head ../surface-head.pt --ranker ../residual-large-hard-seed1/best.pt --calibration ../inference-calibration.json --primary-result ../primary.json --image ../input.png --output ../ranked.json
```

Repeat formal training for all conditions and seeds with the same cache.
The 48-view engineering audit and the pilot precede formal fitting. Every
epoch checkpoint is read back; source hashes and paired sampling are checked.
Binary cache checksums were first recorded after the initial matrix; they are
post-run identities, not a claim of pre/post binary equality. Source image,
mask and background hashes were recorded and subsequently checked separately.

An inference calibration JSON must bind `parent_sha256`, `surface_head_sha256`,
`ranker_sha256` and its selected `threshold`. Prediction checks these bindings
and the primary input hash. Without a primary record it is coarse-only
diagnosis. `benchmark_bird_residual.py --help` documents the matched 500-sample
resident-CUDA timing command. Native B/H predictions are cached in single-n
timings; two-n timings include both independent backbones. Neither is camera
NPU or lens timing. Checkpoints, photos, masks, caches, the production database
and private review exports remain outside Git.

The prepared fit-side queue has 40 images, 80 points and 24 groups, all initially unknown. These are not confirmed errors; none of the selected source frames makes this already-trained parent abstain. See the results for the out-of-fold mining and absence-sampling diagnosis.
