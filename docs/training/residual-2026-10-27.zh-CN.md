# 剩余困难候选的 RGB 与上下文排序

[English](residual-2026-10-27.md) | **简体中文**

容量和真实困难负例对照已完成，结果仍不足以替换保留的主策略。[结果表](../../experiments/residual-2026-10-27/README.zh-CN.md)。

## 实际训练了什么

现有 YOLO26 衍生 n 父模型为 2,455,728 参数，其参数和 BN 统计冻结；前一轮的
6,945 参数鸟面提议头也冻结。本轮增加直接观察局部 RGB 的判别器，
**没有重新端到端训练整个 n 骨干**。

每个候选点提取 24 和 96 输入像素见方的窗口，分别双线性采样到 64×64。
六通道 RGB 经过五层步长 2 卷积和全局池化，再与采样的 128 维冻结 P2/P3 特征、
原候选分数及四种来源标志拼接分类。小/大判别器为 224,049 / 808,417 参数。
单 n 加鸟面头及判别器合计 2,686,722 / 3,271,090 参数；双 n 主策略还保留独立
2,455,728 参数框模型，合计 5,142,450 / 5,726,818。
单 n 数字不含原厂 B/H 支路，不能据此声称整个机身系统只增加一倍参数。

最多保留 24 个预测候选：至多 8 个眼、4 个头中心、4 个整鸟中心、16 个鸟面峰，
按此顺序做 4 像素去重和截断。推理不注入真值点。已有 E/H/B 落点完全保留，
只在主策略放弃时排序；新增输出是粗捕获 `capture_hint`，不是精确眼点。

## 部分监督与校准

原父模型的 375 张社区训练图保持不变。仅按元数据的规则从中留出 5 组 41 张，
给新判别器校准，其余 334 张用于拟合。父模型见过这 41 张，因此它们只是内部校准，
不是独立测试。旧 80 张社区验证图仍是反复使用的开发诊断，历史测试继续隔离。

真实正例只使用已有人工眼点；鸟/头框内部的其他点仍未知。有人工无鸟结论的帧可提供负例；
同时存在人工整鸟框时，距所有框、眼和不确定区域至少 32 像素的点，可作为半权重推导负例。
仅有头框不能推出全图无鸟。这依赖复核覆盖假设，不把模型漏检当负例。

CUB 提供 5,385 张拟合图和 600 张校准图，后者生成原图、小鸟、遮挡三种关联视图，共 1,800 个，
沿用既有训练背景池。可靠掩膜内部为正例，明确添加的合成遮挡为负例，合格背景半权重，边界不确定区忽略。
掩膜沿用 `>127` 二值化后再缩放的规则；保留 CUB 研究许可和背景覆盖假设。

缓存包含 157,697 个拟合点、1,250 个真实校准点、57,089 个公开校准点。
只有已知标签参与拟合。训练/校准额外加入眼点或掩膜内部锚点及随机简单负点，
注入标志和标签不进入网络输入；公开 top-one 指标排除注入锚点。
因此真实校准的锚点接受率不是端到端鸟检出率。

## 匹配对照

每组使用 20261027、20261028 两个抽样种子：

| 条件 | 判别器 | 真实负例抽样 |
|---|---|---|
| small-hard | 小 | 有候选时 75% 选挖掘负例 |
| large-easy | 大 | 随机合格负例 |
| large-hard | 大 | 与 small-hard 相同 |

CUB 负例及合成遮挡抽样在三组相同；同种子的图像顺序一致，小/大困难负例组的点顺序也一致，
大模型简单/困难组初始权重相同。50% CUB、50% 合格真实组，组内再抽图。
每轮 4,096 次缓存图像对呈现，批次 64 帧，AdamW 学习率 .0003、权重衰减 .0001，
CUDA float16 autocast、梯度裁剪 10。损失为加权 BCE 加 .5 倍成对 softplus 排序损失。
上下文特征冻结，RGB 亮度倍率 .9–1.1。

最初六组各 8 轮，全部选中了末轮。保留这批结果后，另存增量计划，将相同六组从匹配初始化重新训练到 32 轮。
延长训练的决定发生在首轮开发诊断后，不冒充事先完整预注册。阈值和选权重规则不变。
共 12 次运行、240 个配置的缓存训练轮，**不是 240 轮完整骨干训练**。

选型首先满足真实校准已知负例误接受不超过 1 帧，再优先保留真实正锚点，
再最大化 CUB 实际候选的“前景命中−5×已知错误”，平局优先更少误接受和更高门槛。
包含完全放弃的门槛。旧社区 80 张预测、旧人工点和 AI 草稿均不用于训练或本轮选型。
鸟面提议头在前一轮已使用相同 CUB 开发来源选型，公开校准也不是新数据。

## 复现

使用固定的可选 [YOLO 依赖](../../requirements-yolo26.txt)及兼容 CUDA PyTorch，输出必须使用 Git 外新路径：

```text
python scripts/training/prepare_bird_residual.py --dataset ../surface-data/dataset.json --parent ../parent.pt --surface-head ../surface-head.pt --output ../residual-cache
python scripts/training/train_bird_residual.py --cache ../residual-cache --output ../residual-pilot --condition large-hard --pilot-steps 200
python scripts/training/train_bird_residual.py --cache ../residual-cache --output ../residual-large-hard-seed1 --condition large-hard --seed 20261027 --epochs 32
python scripts/training/predict_bird_residual.py --parent ../parent.pt --surface-head ../surface-head.pt --ranker ../residual-large-hard-seed1/best.pt --calibration ../inference-calibration.json --primary-result ../primary.json --image ../input.png --output ../ranked.json
```

对三条件、两种子重复正式训练，缓存相同。48 点工程视觉检查和 200 步试跑在正式训练前完成；
逐轮权重保存后读回，检查执行源码和抽样顺序。缓存二进制哈希首次在首批矩阵后记录，
只代表运行后身份，不冒充前后字节一致证据；源图片、掩膜和背景另有前后哈希核验。

推理校准 JSON 需包含 `parent_sha256`、`surface_head_sha256`、`ranker_sha256`、`threshold`。
推理检查这些绑定及主结果的输入哈希。未传入主结果时仅运行粗分支诊断。
`benchmark_bird_residual.py --help` 列出 500 次匹配 CUDA 计时参数。
单 n 计时缓存原厂 B/H 输出，双 n 计时包含两个独立骨干，均不是机身 NPU 或镜头耗时。
权重、照片、掩膜、缓存、生产数据库及私人复核导出不进入 Git。

已准备训练侧40张、80点、24组队列，初始全未知，不代表已确认错误；所选源图在见过它们的父模型上均已有落点。按组交叉预测挖掘和无鸟抽样诊断见结果页。
